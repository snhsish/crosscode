# CrossCode Documentation

Welcome to the CrossCode documentation. CrossCode is a platform for building and deploying code snippets with secure tunneling.

## Overview

CrossCode consists of two main components:

- **CLI**: A command-line tool for managing your tunnel server
- **App**: The desktop application for managing your projects

## Quick Start

1. [Install the CLI](/docs/installation)
2. [Learn CLI commands](/docs/cli)
3. [Download the App](/download)

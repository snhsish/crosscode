# Installation

Get started with CrossCode by installing the CLI tool.

## Prerequisites

- Node.js 18 or later
- npm, pnpm, or yarn

## Install via npm

```bash
npm install -g crosscode
```

## Install via pnpm

```bash
pnpm add -g crosscode
```

## Verify Installation

After installation, verify it works:

```bash
crosscode --version
```
